# Sky Tart Roll

スマホを縦に持ち、端末を傾けて透明なボールを操る3Dブラウザーゲーム。景観も攻略も異なる6つの長距離コースを自由に選び、タルトを集めてゴールへ向かいます。Three.js、Rapier、TypeScript、Viteで構成した静的アプリです。

## 現在の状態

6ステージのうち、エメラルド海岸は入門コースを維持し、残る5ステージは個別に本道を設計しています。砂漠はすり鉢状の螺旋と谷、お菓子は実際に隙間のある飛び石、水晶は下段と上段を結ぶ昇降床、風車は回転橋と横風、ネオンは広い高速レーンと連続ダッシュです。

ダッシュは流れるパネル矢印、発動リング、走行経路に残る軌跡、放射状に流れる速度線、前傾、カメラ、加速音・風切り音を連動させています。新ステージの難易度・実機踏破はプレイヤー試遊で調整します。自動検証では起動と各ギミックの物理成立を確認し、旧来の共通ルート自動操縦は入門コースの回帰確認として残しています。

ゲーム一巡、全6コース、傾き／スティック、ダッシュ／ジャンプ、安全履歴／チェックポイント復帰、独立した記録保存、効果音、支給キャラクターGLBを実装しています。**Pagesは公開済みです。スマホ／iPad実機受入は未実施で、全体検収は完了していません。**

この成果物は指定済みのGitHubリポジトリの `main` に保存し、GitHub Pagesから公開しています。発注仕様の原文は [docs/order.md](docs/order.md)、受入結果は [docs/acceptance.md](docs/acceptance.md) にあります。

## 開発・検証

Node.js 24 LTS推奨（22.12以上）。依存バージョンは `package-lock.json` に固定します。

```sh
npm ci
npm run dev
```

表示されたlocalhost URLを開きます。PCではスティック、または開発確認用の矢印キー／WASDで遊べます。開発サーバーは既定で127.0.0.1にのみ接続します。

```sh
npm run verify
```

整形確認 → TypeScript → ロジック／Rapier試験 → 本番ビルド → ブラウザー試験を実行します。Windowsのブラウザー試験はインストール済みMicrosoft Edgeを使用します。他OSでは初回に `npx playwright install chromium`（LinuxでOS依存も必要なら `npx playwright install --with-deps chromium`）を実行してください。Playwrightは実機センサー検証の代用ではありません。

個別コマンド: `npm run format:check`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:browser`。編集後の整形は `npm run format`。ブラウザー試験の失敗時は `test-results/` に診断用スクリーンショット／traceを保存します。

```sh
npm run build
npm run preview
```

`dist/` が配信対象です。`file://` で直接開かず、HTTPサーバーから配信してください。`base: './'` によりGitHub Pagesのリポジトリ配下でも動作します。外部CDN、アカウント、バックエンド、分析通信は使用しません。

## 遊び方

1. 自由にコースを選び、傾きかスティックを選択します。
2. 傾きでは楽な持ち方のまま「基準を登録して出発」を押し、必要なセンサー許可を与えます。実際の値を受信してから開始します。拒否／非対応／未受信ならスティックへ切り替えられます。
3. 右へ傾けると右、前へ倒すと奥へ加速。逆向きに操作すると減速できます。スティックは移動量で強さが変わります。手動ジャンプと独立ブレーキはありません。
4. 金色の矢印はダッシュ、桃色の矢印はジャンプ。踏むと自動発動します。ジャンプは助走をつけて台の中央を通りましょう。最終コースはダッシュからジャンプにつなげます。
5. 落下すると少し前の安全な道へ戻ります。安全な履歴がない／短時間の再落下が続く場合は最後のチェックポイントへ戻ります。未通過時のみスタートへ戻ります。
6. 「Ⅱ」で中断・感度・BGM選択・BGM音量・ミュート・操作方式変更・基準リセット・再挑戦を選べます。BGMは各ステージ開始時に6曲からランダム再生するか、好きな1曲を固定できます。バックグラウンドから戻った後は明示的に再開します。

残機と制限時間はありません。落下・中断・バックグラウンド時間もタイムに含みます。タルトは任意収集で、同じラウンドでは取り直せません。「最初から再挑戦」でタイム、タルト、チェックポイント、履歴を初期化します。

## 記録

ゴール時にのみコース別ベストタイム（最小）と最多タルト（最大）を独立保存します。全収集は✦で表示します。保存キーは `sky-tart-roll.v2`。旧版の操作方式・感度・ミュートは引き継ぎ、作り直したコースの旧記録は混在させません。

同じブラウザー・同じoriginのlocalStorageです。端末間同期や途中ラウンド復元はありません。ブラウザーデータ削除で消えます。破損／保存禁止でもゲームは起動し、保存できない場合は案内します。

## GitHub Pagesでの公開

1. 収録済み支給GLBの公開リポジトリ収録・HTTPS配信の許諾を最終確認します。正式名称や実機受入の結果も反映します。
2. 設定済みのGitHubリポジトリへこのコミットをpushします。`node_modules/`、`dist/`、診断ログ、認証情報を含めません。
3. リポジトリの **Settings → Pages → Source: GitHub Actions** を選びます。
4. Actionsの **Verify** が成功したことを確認し、**Deploy Pages → Run workflow** を明示的に実行します。公開workflowは手動起動のみです。
5. 完了したdeployジョブのURLを実機で開き、[受入表](docs/acceptance.md) のHTTPS・センサー・表示・性能項目を埋めます。
