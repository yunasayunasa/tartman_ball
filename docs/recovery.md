# 復旧・取り消し

現時点では初回コミットも公開も行っていません。ローカル成果物はこの `sky-tart-roll` フォルダーだけです。取り消す場合はこのフォルダーを保管用へ移すことで元の作業フォルダーに影響を与えず撤回できます。依存取得用一時キャッシュはリポジトリ外にあり、納品物に含みません。

公開後は成功したActionsのコミットSHAと公開日を `docs/acceptance.md` に追記し、必要ならその版にリリースタグを付けます。

旧版へ戻す場合は、稼働中の作業ツリーを上書きせず、別フォルダーへリポジトリをcloneし、戻したいタグ／コミットをcheckoutします。`npm ci` → 必要なPlaywrightブラウザー導入 → `npm run verify` で旧版を再検証します。

公開用の履歴変更は通常のrevertコミットまたは旧版から作る修正ブランチ／PRで行います。force pushや `reset --hard` は不要です。戻す差分をレビューし、公開用ブランチへ反映した後、手動のDeploy Pagesを実行します。HTTPS URLで起動・センサー・保存記録の互換性を確認します。

ブラウザーの記録は配信originのlocalStorageにあります。公開版の巻き戻しだけでは記録を消しません。保存形式の変更時はversionと移行方針を決め、既存記録を不用意に破棄しないでください。
