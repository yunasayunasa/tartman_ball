# 調整・GLB組み込みガイド

## 操作と物理

`src/config.ts` の `tuning` に係数を集めています。球半径0.52、重力-19、通常速度9、ダッシュ速度15、ジャンプ初速12、物理120Hzが現在値です。値変更後は `npm run verify` を実行してください。ジャンプ距離は重力・減衰・助走速度と連動します。

入力はW3CのZ-X′-Y″姿勢をQuaternionにし、登録した姿勢の逆回転と現在姿勢の積から画面法線の傾きを取り出します。画面方向補正 → デッドゾーン1.4° → 最大23° → 1.35乗カーブ → 長さ制限 → 50ms程度の平滑化を適用します。感度は0.5〜1.8です。基準40°前後だけでなく85°・100°付近と±180°境界も疑似入力試験に含めています。磁気・端末センサー固有のノイズは実機で検証してください。

接地／空中の横力は同じ入力経路です。空中補正は22%、空中減衰0.12。ダッシュ後2秒間は上限15、それ以外は9。球はCCD有効、足場は固定cuboidです。ジャンプ台は球の中心が上面高さ付近にあり上昇していない場合に発動し、その平面範囲を離れるまで再発動しません。

## コース

`src/courses.ts` の `courses` を編集します。ルート折れ点・道幅・明示した隙間から固定配置を作るデータ構造です。ランダム生成やステージエディターではありません。

`route` は道の中心を示す点列。コース1だけは角を二次曲線で丸め、回転した単純な箱を重ねて緩いカーブにしています。`widths` は各道の幅、`gaps` は足場を置かない接続番号です。`checkpoints` は広い島の中心で、全CPから静止状態の試験を行います。`pads` は方向・大きさ付きで、金はdash、桃はjump。台の上と周囲1.2mは安全復帰候補から除外します。タルトは道の中心に7mおきで、一意IDを持ちます。独立した配置に変える場合もIDは重複させません。

位置だけでなく、縦画面カメラから次の足場が見えるか確認してください。ジャンプ台は足場の末端寄りに置き、着地点は十分広くします。ダッシュジャンプは速度を落とさず進める直線上に配置します。

## 復帰

`src/round.ts` が優先順位を管理します。`src/physics.ts` が接地と安全領域を検査します。

- 0.65秒以上安定して接地した場所を0.45秒間隔で記録し、最大28件に制限。
- 端から0.95m以内、空中、ギミック上／周囲を候補にしない。
- 1.2秒以上前の候補までさかのぼり、復帰時にもう一度安全性を確認。
- CP更新で旧区間の履歴を消去。復帰先以降の履歴も破棄。
- 5秒以内の再落下が2回続くとCPへ切り替え。
- 復帰時に並進・回転速度と入力を解除し、0.65秒は横力を抑制。

現行コースは頭上障害物のない固定平面のみです。頭上障害物や多層構造を加える場合は `safeAt` を拡張し、球全体の空間照会を追加する必要があります。今回はその地形を含みません。

## カメラと描画負荷

`src/view.ts` の `draw` / `resize` を調整します。プレイ中の方位は固定、球に対して上15・手前17、奥8付近を注視。カメラ位置の追従は指数平滑化です。復帰時は `snap` で即座に新しい位置へ移り、落下はY=-0.5より下へ追いません。

描画比率は最大1.75、動的シャドウなし、球は透過材質＋輪郭。雲は足場より低く配置します。負荷が高い端末では比率上限と雲・タルトの分割数を調整し、キャラクター表示込みの実測を取り直します。

## 支給GLB

支給GLBは `public/character.glb` に元ファイルのまま収録しています。SHA-256は `683DCA055612791687EF5246114CBDE79D64E4A3EAE2FEA3C2A93257D3A0A370` です。Tripo生成、13メッシュ・1埋め込みJPEG・16アニメーションを確認しました。

1. ファイルの公開リポジトリへの収録・HTTPS配信・アニメーション利用の許諾を確認します。
2. 元GLBを変更せず `public/character.glb` に保持します。
3. `src/config.ts` はURLを `'character.glb'`、走行クリップを1秒の `NlaTrack` に設定済みです。
4. 走行クリップ名を変更する場合はGLB内の正確な名前を指定します。空なら名前に `run` または `走` を含むクリップを選び、それもなければ読み込みエラーで止めて再試行を案内します。別のモーションを黙って走行扱いにはしません。
5. 元モデルの正面が+Zでなければ `yaw`（ラジアン）で補正します。`height` で高さを指定し、幅／奥行きも球内に収めます。モデルのBoundingBoxから足元を合わせます。
6. `NlaTrack` のHipに25フレームのpositionトラックがあるため、`rootMotionNodes` は `['Hip']` です。実行時の複製クリップでXZを最初の値に固定し、Yと手足のトラックを維持します。骨盤や足の全positionを一括除去しません。
7. 接地移動で走行、空中／中断時に走行停止、移動方向への旋回、球の回転と独立した直立、ループ時の位置ずれを確認します。
8. A22とA27を支給品込みで再検証し、素材情報・サイズ・クリップ名・権利者を第三者素材一覧へ追記します。

必要なモーションやモデルが読み込めないときは、原因と再読込ボタンを表示します。設定が空のときだけ仮マスコットを使用します。支給品のエラーを仮表示で隠しません。

## 音

`src/audio.ts` のWeb Audioによる短い正弦波音です。タルト・ダッシュ・ジャンプ・落下・CP・復帰・ゴールで音程を変えます。ユーザー操作でAudioContextを開始し、再生終了後にノードを切断します。ミュートでもトーストと色の変化で状態を確認できます。
